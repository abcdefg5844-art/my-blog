## 고칠 것
4. **저장 대기 중인 변경이 사라짐** — 이 창에 아직 저장하지 않은(디바운스 대기 중인) 변경이 있을 때 다른 창의 변경을 받으면, 이 창의 변경이 사라지지 않게 한다. 권장: 다른 창 값을 불러오기 전에 이 창의 대기 중 변경을 다른 창 그림 위에 합친다(이 창이 바꾼 칸만 덮어쓰기). 합친 뒤에는 바로 저장해 다른 창도 같은 결과를 갖게 한다. 두 창이 번갈아 빠르게 그려도 무한히 서로 저장을 주고받지 않아야 한다.
5. **현재 색·도구가 다른 창 것으로 바뀜** — 다른 창의 변경을 받을 때는 그림(픽셀)만 반영하고, 이 창의 현재 도구·색·사용자 색·격자 표시·PNG 배율 같은 설정은 유지한다. 새로고침으로 처음 불러올 때는 지금처럼 저장된 설정을 복원한다.
