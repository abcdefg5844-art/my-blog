## 확인할 것
1. 문제 6: 다른 창이 설정만 바꿔 저장하면 이 창의 되돌리기·다시 실행 기록이 유지되는지. 그림이 바뀌면 "받기 전 그림"이 한 단계로 쌓여 되돌리기로 돌아갈 수 있는지. 전체 지우기 후 다른 창이 저장해도 지운 창에서 되돌리기로 지우기 전 그림을 복구할 수 있는지. 기록 한도 100 유지
2. 회귀: 2차 수정(미공유 변경 합치기, 저장 주고받기 반복 없음, 이 창 설정 유지), 1차 수정 3건, `test.html` 53개, 그리기·지우개·채우기·되돌리기·다시 실행·자동 저장·복원·PNG, 콘솔 오류
3. 코드 리뷰: 다른 창 값을 받은 뒤 되돌리기를 했을 때의 저장·전파가 다시 다른 창의 기록을 이상하게 쌓지 않는지(두 창에서 번갈아 되돌리기)
