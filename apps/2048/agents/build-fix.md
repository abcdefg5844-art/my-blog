## 고칠 것
1. **오버레이 포커스** — 승리/게임 오버 오버레이에 `role="dialog"`, `aria-modal="true"`, 제목과 연결된 `aria-labelledby`를 붙이고, 열려 있는 동안 Tab/Shift+Tab이 오버레이 버튼 안에서만 돌게 한다. 닫히면 보드로 포커스 복귀(기존 동작 유지).
2. **reduced-motion의 `+N`** — `prefers-reduced-motion: reduce`이면 `+N` 요소를 아예 만들지 않는다(점수 숫자는 즉시 갱신). 화면 낭독기 알림은 그대로.
3. **아주 작은 iframe에서 하단 잘림** — 300×360 같은 작은 iframe에서도 보드가 잘리지 않게 한다. 고정 추정치(`--chrome: 130px`)에 의존하지 말고, 헤더·점수판 줄바꿈까지 반영되도록 레이아웃(예: flex 세로 배치 + 보드가 남은 높이와 폭 중 작은 값을 쓰는 방식, 또는 실제 높이 측정)으로 해결한다. 375×812, 400×480, 343×440, 600×520, 400×400에서 기존처럼 잘 보여야 한다.
4. **`alertMessage` 토큰 처리** — `announce`처럼 예약한 setTimeout을 취소하거나 토큰으로 오래된 알림을 무시해서, 새 게임 직후 이전 알림이 늦게 쓰이지 않게 한다. 새 게임 시작 시 대기 중인 알림도 정리한다.
